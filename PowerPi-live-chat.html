Connect your Power BI dataset

Paste an Azure AD access token scoped for the Power BI Service API, plus your workspace and dataset IDs. This tool queries the dataset directly with a DAX EVALUATE statement over the REST API — it never leaves your browser and nothing is saved anywhere. Don't have a token handy? Use Demo mode below to try the chat with sample data first.

Chat works instantly with no API key at all — a built-in rule-based engine answers counts, sums, averages, filters, and "top/bottom N" questions directly from the loaded data, for free, fully offline. Adding a Claude API key below is optional — it upgrades answers to handle more open-ended, free-form phrasing, at a small per-question cost.

If you do add a key: it's sent directly to Anthropic from your browser and nowhere else, but anyone with access to this page (view-source, devtools) can read it while it's filled in — fine for testing on your own machine, but don't put a real key in a page others will open (a hosted URL, a Teams tab). For that, route the chat call through a small backend that holds the key server-side instead — ask if you'd like that scaffolded.
